1. Multi-Agent System Architecture & LangGraph State Orchestration

Traditional systems rely on static scoring rules, while pure LLM systems suffer from hallucinations and lack auditability. This architecture bridges deterministic rules with AI document understanding.

LangGraph State Graph & Node Topography (src/agent/)

  • data_extraction: Ingests PDF uploads (MVRs, loss runs, inspection reports) using PyPDF2 and extracts structured risk fields.
  • web_search (WebSearchAgent): Selects between Wikipedia API (entity verification) and Bing Search API (litigation & risk indicators).
  • financial_data (FinancialDataAgent): Queries SEC EDGAR for public financials or Dun & Bradstreet (DnB) for private credit scores.
  • risk_assessment: Evaluates extracted claim history, serious accidents, and operational factors.
  • premium_calculation: Executes a deterministic Python rules engine (src/premium/).
  • llm_reasoning & decision: Combines rule outputs with evidence chunks to produce an explainable accept/decline decision.

Conditional Loops & Validation Checkpoints

  • Completeness Check: If data extraction flags missing fields, execution loops to web search to enrich the state.
  • Outlier & Contradiction Check: If pricing conflicts with extreme risk profiles, conditional edges route back to re-evaluate parameters.
Result: Reduced underwriting turnaround time by 30–40% while maintaining 100% deterministic auditability for compliance.

2. Hybrid Retrieval Pipeline & pgvector RAG Architecture

Dense policy documents and loss runs contain complex jargon and exact policy numbers that vector search alone fails to capture.

4-Stage Hybrid Retrieval Pipeline (src/retrieval/)

  • Stage 1 (BM25 Full-Text Search): Captures exact vehicle IDs, policy codes, and violation types.
  • Stage 2 (Dense Vector Search): Queries Aurora/PostgreSQL with pgvector using cosine distance for semantic concept matching.
  • Stage 3 (Reciprocal Rank Fusion - RRF): Blends BM25 keyword rankings and semantic vector scores into a unified candidate set.
  • Stage 4 (Cross-Encoder Re-Ranking): Passes top candidates through a Cross-Encoder model to maximize context precision.
Result: Boosted operational query efficiency by ~40% and eliminated context retrieval failures.

3. Core Business Rules Engine, Security Guardrails & External Agents

Mathematical predictability for premium calculation wrapped in zero-trust security.

Deterministic Premium Engine (src/premium/)

  • Base Rates: Sedan ($500), Van ($800), Truck ($1,200), Fleet ($5,000).
  • Surcharges & Constraints: Adds adjustments for prior claims (+50%), serious accidents (+100%), and traffic violations (+25%), enforcing a hard minimum floor of $300.

Enterprise Guardrails (src/security/)

  • Integrated Llama Guard pattern detection for prompt injection filtering in PDF inputs.
  • PII masking in application logs and AWS WAF rate-limiting rules at the API Gateway level.
Result: Underwriters receive fully explainable price breakdowns backed by external web verification and zero-trust security.

4. MLOps, Observability & Continuous Evaluation Framework

  • LangSmith: Captures full trace logs for every LangGraph workflow node execution time and token usage.
  • Arize Phoenix: Tracks output distributions and embedding drift over time for incoming loss run PDFs.
  • Ragas: Measures retrieval faithfulness, answer relevance, and context precision continuously.
  • Prometheus + Grafana: Exposes custom latency histograms, HTTP status counters, and analytics via FastAPI.
